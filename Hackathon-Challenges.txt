Local Agentic Systems
Build autonomous AI agents that reason, plan, and act — entirely on local or hybrid infrastructure. Your agent runs on our ZGX Nano using multi-step reasoning and tool-use, with zero dependency on cloud AI APIs. This is the core track: pure local intelligence.

Agent must run on the event's ZGX Nano (local or hybrid)
Local or hybrid inference only — no cloud AI API calls for core reasoning
Multi-step reasoning or tool-use required (not just single-turn chat)
Agent should complete a real, useful task autonomously
Demonstrate at least one agentic loop with tool calls in the live demo

Secure AI
AI security is the next frontier. Build systems that protect AI models from adversarial attacks, detect prompt injection, secure multi-user inference on ZGX Nano, or implement access controls for locally-deployed LLMs. Create reasoning logic to identify, alert, amend, and monitor patches. Pit different models against each other to change vectors and assess how different models and agent harnesses navigate security issues.

Project must address AI security — model, inference, or deployment layer
Local or hybrid architecture required — demonstrate on the ZGX Nano
Show a real attack vector and your mitigation strategy
Include a threat model in your pitch documentation
